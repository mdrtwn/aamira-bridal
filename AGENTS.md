# Aamira Bridal Project

This repository contains the Aamira Bridal website.

Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

Project Rules

- Never delete files without checking references.
- Never change unrelated pages.
- Preserve existing functionality.
- Keep code clean.
- Use reusable components whenever possible.
- Run lint before completing.
- Run build before completing.
- Explain breaking changes.
- Do not create duplicate components.
