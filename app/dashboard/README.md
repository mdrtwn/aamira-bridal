# Aamira Dashboard

This directory is reserved for the internal Aamira dashboard.

The two brands have separate modules while sharing future authentication,
permissions, navigation, and reusable dashboard components.

- `aamira-basic/` — ready-to-wear commerce operations
- `aamira-bridal/` — bridal collections, appointments, and inquiries

No public dashboard route is exposed yet. Authentication and the dashboard
shell should be implemented before adding operational pages.
